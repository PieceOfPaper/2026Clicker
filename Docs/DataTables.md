# 데이터 테이블 설계 메모

이 문서는 기획 과정에서 **코드에 하드코딩하지 않고 데이터 테이블로 관리해야 할 값**을 잊지 않기 위한 메모입니다.

- README는 플레이 규칙과 확정된 기획을 설명합니다.
- 이 문서는 테이블 후보 필드, 현재 기본값, 결정 상태를 관리합니다.
- 현재 값은 플레이 테스트 전 기준이며 추후 조정할 수 있습니다.
- `확정`은 현재 기획에 합의된 값, `미정`은 구현 전에 추가 결정이 필요한 값입니다.
- 아래 테이블 이름과 필드명은 개념안이며 실제 Unity 데이터 구조는 구현 단계에서 정합니다.

## 현재 확정된 기본값

| 항목 | 현재 값 | 상태 | 비고 |
| --- | --- | --- | --- |
| 스테이지당 일반 몬스터 수 | 10 | 확정 | 보스는 포함하지 않음 |
| 보스 제한시간 | 30초 | 확정 | 스테이지 테이블에서 조정 가능하게 구성 |
| 보스 실패 후 반복 대상 | 해당 스테이지 일반 몬스터 10마리 | 확정 | 1번부터 10번까지 순서대로 반복 |
| 반복 전투 중 보스 진입 | `보스와 전투` 버튼 | 확정 | 보스는 자동으로 재등장하지 않음 |
| 자동 전투 | 추후 해금 | 방향 확정 | 현재 MVP에서는 제외 |

## StageTable 후보

스테이지 단위의 진행 규칙과 콘텐츠 연결 값을 관리합니다.

| 필드 후보 | 용도 | 현재 값 | 상태 |
| --- | --- | --- | --- |
| `StageId` | 스테이지 식별자 | 미정 | 미정 |
| `NormalMonsterCount` | 보스 전 일반 몬스터 처치 수 | 10 | 확정 |
| `NormalMonsterSequence` | 등장할 일반 몬스터 ID와 순서 | 미정 | 미정 |
| `BossMonsterId` | 스테이지 보스 ID | 미정 | 미정 |
| `BossTimeLimitSeconds` | 보스 제한시간 | 30 | 확정 |
| `BackgroundId` | 스테이지 배경 리소스 ID | 미정 | 미정 |
| `RewardMultiplier` | 스테이지 보상 배율 | 미정 | 미정 |

## MonsterTable 후보

일반 몬스터와 보스의 전투 수치 및 리소스 연결 값을 관리합니다.

| 필드 후보 | 용도 | 현재 값 | 상태 |
| --- | --- | --- | --- |
| `MonsterId` | 몬스터 식별자 | 미정 | 미정 |
| `MonsterType` | 일반 또는 보스 구분 | 미정 | 미정 |
| `MaxHp` | 최대 체력 | 미정 | 미정 |
| `BasicCurrencyReward` | 처치 시 기본 재화 보상 | 미정 | 미정 |
| `PrefabId` | 표시할 Prefab 또는 외형 ID | 미정 | 미정 |
| `HitAnimationId` | 피격 애니메이션 ID | 미정 | 미정 |
| `DeathAnimationId` | 사망 애니메이션 ID | 미정 | 미정 |

## TapUpgradeTable 후보

수동 터치 공격과 강화 비용을 관리합니다.

| 필드 후보 | 용도 | 현재 값 | 상태 |
| --- | --- | --- | --- |
| `Level` | 강화 레벨 | 미정 | 미정 |
| `TapDamage` | 해당 레벨의 터치 피해량 | 미정 | 미정 |
| `UpgradeCost` | 다음 레벨 구매 비용 | 미정 | 미정 |
| `MaxLevel` | 최대 레벨 | 미정 | 미정 |
| `DamageGrowthFormula` | 피해량 증가 공식 또는 참조 ID | 미정 | 미정 |
| `CostGrowthFormula` | 가격 증가 공식 또는 참조 ID | 미정 | 미정 |

## CompanionTable 후보

동료 형태의 자동 전투는 현재 MVP에서 제외하지만, 이후 구현할 때 필요한 값을 미리 기록합니다.

| 필드 후보 | 용도 | 현재 값 | 상태 |
| --- | --- | --- | --- |
| `CompanionId` | 동료 식별자 | 미정 | 추후 결정 |
| `UnlockCondition` | 자동 전투 해금 조건 | 미정 | 추후 결정 |
| `AttackDamage` | 자동 공격 피해량 | 미정 | 추후 결정 |
| `AttackIntervalSeconds` | 자동 공격 간격 | 미정 | 추후 결정 |
| `UpgradeCost` | 동료 강화 비용 | 미정 | 추후 결정 |

## 보스 실패 및 재도전 정책

아래 항목은 전투 상태 전환에 영향을 주므로 구현 전에 결정하고, 필요하면 StageTable 또는 별도 설정 테이블로 관리합니다.

| 항목 | 현재 상태 | 결정할 내용 |
| --- | --- | --- |
| 보스 재도전 비용 | 미정 | 무료인지, 재화가 필요한지 |
| 재도전 시 보스 체력 | 미정 | 완전 회복인지, 남은 체력을 유지하는지 |
| 재도전 버튼 전환 시점 | 미정 | 현재 일반 몬스터 전투를 즉시 중단하는지, 처치 후 이동하는지 |
| 보스 조기 포기 | 미정 | 제한시간 전 반복 전투로 돌아갈 수 있는지 |
| 앱 종료 후 보스 타이머 | 미정 | 저장·복원 또는 실패 처리 방식 |

## 입력 및 전투 판정 정책

| 항목 | 현재 상태 | 결정할 내용 |
| --- | --- | --- |
| 터치 피해 적용 시점 | 미정 | 입력 즉시인지, 공격 애니메이션의 타격 프레임인지 |
| UI 터치의 공격 처리 | 미정 | 버튼 조작과 전투 터치가 동시에 발생하지 않도록 입력 영역 정의 |
| 연속 터치 제한 | 미정 | 초당 입력 제한 또는 애니메이션 중 입력 허용 여부 |
