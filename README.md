# 2026Clicker

> 2026년에 클리커는 재밌을까?

## 프로젝트를 시작한 이유

`2026Clicker`는 “2026년에도 클리커 게임은 여전히 재미있을까?”라는 단순한 질문에서 시작했습니다. 익숙하고 직관적인 클릭이라는 행위가 오늘날의 플레이 환경에서도 충분한 몰입감과 성장의 즐거움을 줄 수 있는지, 작은 게임을 직접 완성하며 확인해 보려는 프로젝트입니다.

동시에 이 프로젝트는 Unity CLI와 Codex를 실제 Unity 개발 과정에 활용하는 학습이자 실험이기도 합니다. 기획을 구체화하고, Scene과 UI를 구성하고, 코드를 작성하고, Editor에서 결과를 검증하는 일련의 과정에서 두 도구가 개발자를 얼마나 효과적으로 보조할 수 있는지 살펴봅니다. 단순히 게임 하나를 만드는 데서 그치지 않고, 사람과 AI가 함께 작업하는 더 나은 개발 흐름을 찾아가는 것을 또 하나의 목표로 삼습니다.

아래 내용은 이 실험을 통해 만들어 갈 간단한 클리커 게임의 기획 문서입니다. 게임의 방향과 구현 범위가 바뀌면 이 문서도 함께 갱신합니다.

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 클리커 / 방치형 |
| 플랫폼 | 미정 |
| 플레이 방식 | 클릭으로 재화를 얻고, 성장 요소를 구매해 생산량을 높인다. |
| 목표 플레이 시간 | 미정 |
| 핵심 재미 | 짧은 조작으로 수치가 빠르게 성장하는 만족감 |

## 2. 핵심 콘셉트

- 한 줄 소개: 미정
- 테마 및 세계관: 미정
- 차별점: 미정
- 주요 대상 플레이어: 미정

## 3. 핵심 게임 루프

1. 화면의 주요 대상을 클릭한다.
2. 클릭 보상으로 재화를 획득한다.
3. 재화로 클릭 능력이나 자동 생산을 강화한다.
4. 더 많은 재화를 획득하고 새로운 성장 요소를 해금한다.
5. 필요하면 초기화 보상을 통해 더 빠르게 다시 성장한다.

## 4. 재화

| 재화 | 획득 방법 | 사용처 | 비고 |
| --- | --- | --- | --- |
| 기본 재화 | 클릭, 자동 생산 | 기본 강화 구매 | 이름 미정 |
| 특수 재화 | 업적, 초기화, 특별 보상 | 영구 강화 | 도입 여부 미정 |

## 5. 성장 시스템

### 클릭 강화

- 클릭 1회당 획득량을 증가시킨다.
- 가격 증가 공식: 미정
- 최대 레벨: 미정

### 자동 생산

- 일정 시간마다 자동으로 재화를 생산한다.
- 생산 주기와 강화 방식: 미정
- 오프라인 보상 도입 여부: 미정

### 초기화 및 영구 성장

- 일정 조건을 달성하면 진행도를 초기화하고 영구 보상을 얻는다.
- 도입 여부와 해금 조건: 미정

## 6. 콘텐츠

- 강화 항목: 미정
- 단계 및 지역: 미정
- 업적: 미정
- 일일 보상: 미정
- 이벤트: 미정

## 7. 화면 구성

### 메인 화면

- 현재 보유 재화
- 클릭 대상
- 클릭당 획득량
- 초당 자동 생산량
- 강화 메뉴 진입 버튼

### 강화 화면

- 강화 이름과 현재 레벨
- 현재 효과와 다음 단계 효과
- 구매 가격
- 구매 가능 여부

### 설정 화면

- 배경음 및 효과음 조절
- 데이터 저장 및 초기화
- 게임 정보

> UI 텍스트는 기본적으로 TextMesh Pro(TMP)를 사용합니다.
